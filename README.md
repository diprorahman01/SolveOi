# SolveOi — scaffold

This ZIP is a **folder and route scaffold**, not a complete standalone Next.js application.

## Merge into your existing app
1. Back up `C:\Projects\SolveOi`.
2. Extract this archive to a temporary location.
3. Copy missing folders and files into `C:\Projects\SolveOi`.
4. **Keep the existing `web/package.json`, `web/src/app/layout.tsx`, `web/src/app/page.tsx`, `web/src/app/globals.css`, `web/tsconfig.json`, and Next.js config files** rather than overwriting them.
5. In `C:\Projects\SolveOi\web`, run `npm install` (if needed) and `npm run dev`.

All new site pages are minimal placeholder components. Replace content and styles as you design the website.
The folders `apps/` and `packages/` are placeholders for later development.
